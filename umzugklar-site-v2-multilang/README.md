# UmzugKlar

Коммерческий MVP сайта перевозочной компании на Next.js + TypeScript.

## Реализовано

- адаптивная главная с услугами, ценами, портфолио, FAQ, контактами и юридическими страницами;
- быстрый расчёт на главной и пошаговый калькулятор на `/calculator`;
- серверный endpoint `POST /api/calculate`: браузер передаёт только исходные параметры, цена рассчитывается на сервере;
- конфигурация тарифов вынесена в `config/pricing.ts`;
- базовые SEO-метаданные, `robots.txt` и `sitemap.xml`.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Проверка production-сборки: `npm run build`.

## Перед публикацией

Замените демонстрационные телефон, e-mail, WhatsApp-ссылки, адрес, фото и юридические тексты на реальные. Для production-версии следующими этапами нужны: PostgreSQL/Prisma для сохранения расчётов и заявок, форма с антиспамом и rate limiting, SMTP/Telegram интеграции, настоящая Google Map, локализованные маршруты и переводы, а также юридическая проверка GDPR-документов.
