# Kushch Services

Сайт компании по переездам: Next.js 16 (App Router) + TypeScript, без тяжёлых зависимостей.
Четыре языка интерфейса — DE / EN / UK / RU.

## Что реализовано

- адаптивная главная: услуги, процесс, три тарифа, портфолио, география, FAQ, контакты, юридические страницы;
- быстрый расчёт на главной и пошаговый калькулятор на 7 шагов (`/calculator`);
- отдельная страница заявки (`/anfrage`) с итогом расчёта и выбором способов связи;
- серверные endpoint-ы: `POST /api/calculate` (расчёт) и `POST /api/request` (заявка);
- все тексты, включая подписи услуг, тарифы, placeholder-ы и сообщения об ошибках, лежат в словарях и переключаются языком;
- ссылки из раздела «Наши услуги» и тарифов открывают калькулятор с уже выбранными настройками;
- собственные выпадающие списки, поле расстояния с кнопками −/+ и явной единицей измерения;
- единая дизайн-система: токены радиусов, теней, отступов, типографики;
- SEO: локализованные метаданные, `robots.txt`, `sitemap.xml`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка
```


## Как править тексты и добавлять язык

1. Немецкий словарь `config/i18n/de.ts` — источник набора ключей.
2. Остальные локали объявлены как `Record<CopyKey, string>`, поэтому забытый ключ ломает сборку, а не показывается немецким текстом.
3. Новый язык: добавить файл словаря, зарегистрировать его в `config/i18n/index.ts` и в `localeLabels`.
4. `translate()` больше не подменяет отсутствующий перевод немецким: в dev-режиме выводится предупреждение в консоль.

| Быстрый расчёт | `/calculator?area=…&distance=…&from=…&to=…` | переносит все значения |

## Заявка

- Кнопка «Отправить заявку» на шаге 7 ведёт на `/anfrage`, расчёт переносится через `sessionStorage` (`lib/requestSummary.ts`).
- Обязательные поля: имя и минимум один способ связи (Telegram, Instagram, Viber, E-mail, телефон). Способы можно комбинировать.
- `POST /api/request` валидирует данные на сервере и возвращает коды ошибок (`name`, `contacts`, `email`, `phone`, `consent`), которые интерфейс переводит на нужный язык.

## Публичная демо-версия (GitHub Pages)

Песочница превью закрыта служебным токеном, поэтому открыть из неё ссылку в обычном
браузере нельзя. Для публичного адреса есть статическая сборка и workflow публикации.

**Что нужно один раз:** репозиторий → **Settings → Pages → Build and deployment →
Source: GitHub Actions**.

После этого каждый пуш в `main` или в рабочую ветку автоматически публикует сайт:

```
https://<владелец>.github.io/<репозиторий>/
```

Workflow сам подставляет префикс пути из имени репозитория, поэтому переименование
репозитория (например в `kushch-services`) даст более короткий адрес без правок в коде.

### Как выглядит демо-сборка

| Обычная сборка | Демо на GitHub Pages |
| --- | --- |
| Расчёт цены на сервере (`/api/calculate`) | Тот же алгоритм из `config/pricing.ts` считается в браузере |
| Заявка уходит через `/api/request` | Открывается почтовый клиент с готовым письмом на `kustimofej@gmail.com` |
| Стек Next.js + серверные роуты | Статический экспорт (`output: export`) |

Локально демо собирается командой:

```bash
NEXT_PUBLIC_BASE_PATH=/- npm run build:static    # результат в out/
```

## Перед публикацией

1. **Доставка заявок.** Сейчас `POST /api/request` логирует заявку (`console.info`) и ничего не отправляет. Нужно подключить SMTP, Resend, Telegram-бота или CRM-вебхук в `app/api/request/route.ts`.
2. **Антиспам.** Добавить honeypot-поле и rate limiting на оба API-роута.
3. **Юридические данные.** В `config/company.ts` указаны реальные телефон и e-mail; адрес, правовая форма, VAT ID и регистрационные данные Impressum — заглушки.
4. **Домен.** `company.site` (`https://kushch-services.de`) — заглушка, влияет на canonical, `sitemap.xml`, `robots.txt`.
5. **Логотип.** Знак и вордмарк «Kushch Services» собраны в `components/Logo.tsx`. Если есть официальный файл — положить в `public/logo.svg` и заменить содержимое компонента.
6. **Согласие на обработку данных.** Чекбокс в форме заявки ссылается на `/datenschutz`; текст политики конфиденциальности — заглушка.
7. **Папка `umzugklar-static-indexhtml/`** — устаревшая статическая версия сайта. В текущей сборке не используется и правки в неё не переносятся.
